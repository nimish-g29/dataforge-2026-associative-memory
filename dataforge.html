An interactive explainer · associative memory & synaptic plasticity

One synapse can hold many memories — until it can't.

A fixed-size memory can store several associations by summing them into the same weights. It doesn't fail all at once: as more associations share the same synapses, or as stored keys become more alike, retrieval degrades smoothly because of interference, not catastrophic collapse. The rule, in full

Mini-objectiveAfter this section you should be able to state the write rule and the read rule from memory, and predict what happens to one specific synapse as new memories are added.

Each memory is a pair: a key (the cue you'll use later to ask for it back) and a value (what you actually want to remember). Both are vectors of +1s and −1s.

write:  M ← M + key ⊗ value   (M[i][j] += key[i]·value[j] for every cell)
read:   value_estimate = sign( Mᵀ · key )

Where this shows up in BDH

Mini-objectiveAfter this section you should be able to name where the Hebbian write rule appears inside BDH, what's different there (sparsity, locality, graph structure vs. a flat matrix), and which claims are developer-reported vs. independently checked.

Pathway's Dragon Hatchling (BDH) doesn't use this mechanism as an analogy — it's built from it. In BDH, attention itself is reported to emerge from local neuron-particle interactions whose synapses are updated with a Hebbian rule: co-active neurons strengthen the connection between them, the same outer-product write above, distributed across a scale-free network instead of one dense matrix.

This sandbox's write/read rule

M ← λM + key ⊗ value value_est = sign(Mᵀ · key)

Dense and global: every cell can be touched by every memory, and every key can bind to any value. λ adds forgetting but not sparsity or locality.

BDH's Hebbian synapse update

synapse(i,j) strengthens when neuron i and neuron j are co-active — a local, sparse write over a scale-free particle graph

Sparse and local: each neuron only writes to its graph neighbors, and activity itself is sparse, so far fewer synapses compete for the same signal at once.

A connection worth stating carefully: sparsity acts like a lever on the same interference you just controlled with the correlation slider. Two sparse activation patterns are, on average, far less likely to overlap than two dense ones — so sparse activity effectively lowers the "correlation" between the representations competing for the same synapses, which pushes the capacity cliff further out. This structural link between sparsity and memory capacity is studied directly in modern Hopfield network research (Hu et al., "On Sparse Modern Hopfield Model," NeurIPS 2023) — it is not a specific measured BDH number, so I'm not stating one for BDH itself.

What's actually changing in each case is the same category of object — synaptic state, not the model's trained "slow" weights. In this sandbox that's the matrix M; in BDH it's the graph's synapse strengths, updated continually as the model processes a sequence. That's also why BDH-CQ, a later system in the same family, can adapt to a new task from a handful of demonstrations with no gradient update: the demonstrations rewrite synaptic/contextual memory, not the model's parameters — the same write-then-read pattern from the sandbox, at a very different scale.

What this demo is, and isn't: the matrix above is an independent toy reimplementation built to make the write/read rule visible and small enough to overload by hand. It is not the official BDH model, does not reproduce BDH's reported benchmark numbers, and does not include BDH's sparsity, locality, or scale.

One limitation worth remembering

This demo makes interference feel gradual and manageable at moderate dimension and a dozen or two patterns. That's the point being taught — but it's easy to over-generalize. A common misconception is that "the model just remembers more as it gets bigger," as if capacity scales for free. It doesn't: capacity here scales with dimensionality relative to how many associations are packed in and how correlated they are, not with size alone. A larger BDH network has more neurons and synapses to distribute writes across, but the same superposition trade-off is still operating underneath — just harder to see directly at scale.
